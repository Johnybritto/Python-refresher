## Tiny Lesson

### 1. Normal Code vs GenAI
Normal Python code follows exact rules you write.

Example:

```python
print(2 + 2)
```

This always gives the same result.

GenAI is different.

A GenAI model generates a response based on patterns it learned from large amounts of text and data.

That means:
- it can produce useful answers
- it can also be vague or wrong
- the way you ask matters

## One Small Exercise

### 2. Three Core Words

`model`
- the AI system that generates output

`prompt`
- the instruction or question you give the model

`response`
- the output the model gives back

Simple example:

Prompt:
`Explain what a list is in Python.`

Response:
`A list is an ordered collection of items in Python.`

### 3. Why Prompt Quality Matters
These two prompts ask for nearly the same thing:

Weak prompt:
`Tell me about Python.`

Clearer prompt:
`Explain Python lists in 3 short bullet points for a beginner.`

The second prompt is better because it gives:
- the topic
- the format
- the audience
