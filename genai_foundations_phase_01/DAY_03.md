## Tiny Lesson

### 1. What Makes a Prompt Weak
A weak prompt is usually too broad, too vague, or missing useful instructions.

Weak prompts often miss:
- the exact topic
- the audience
- the format
- the size of the answer

Example:

`Teach me coding.`

This is weak because the model does not know:
- what coding topic you want
- how deep to go
- how short or long the answer should be

### 2. What Makes a Prompt Better
A better prompt gives the model clearer limits.

Useful prompt parts:
- topic
- audience
- format
- length
- example if needed

Weak prompt:
`Explain loops.`

Better prompt:
`Explain Python for loops to a beginner in 3 short bullet points with 1 small example.`

The better prompt is easier to answer well because it is more specific.

### 3. Constraints Improve Output
Constraints are small limits or instructions inside the prompt.

Examples of constraints:
- `in 3 bullet points`
- `for a beginner`
- `with 1 example`
- `in simple language`

Constraints help because they:
- reduce vagueness
- guide the answer shape
- make the result more useful

Weak prompt:
`Help me learn dictionaries.`

Stronger prompt:
`Explain Python dictionaries to a beginner in simple language using 3 bullet points and 1 example.`
