# LeetCode-Style Practice

## Purpose
This file is for beginner-friendly coding questions that feel like LeetCode practice.

In this phase, we will keep them small and practical.

We will focus on:
- strings
- lists
- dicts
- sets
- functions
- debugging
- basic time complexity thinking

## How We Will Use This File
- start with easy logic questions
- solve with clean Python
- discuss correctness
- then discuss readability
- then discuss time complexity
- then discuss space complexity

## Rule
Do not jump to hard problems too early.

First build confidence with easy problems.

## Practice Order

### Level 1: Very Small Problems
1. Find the largest number in a list
2. Count vowels in a string
3. Reverse a string
4. Check if a number is even
5. Count how many times a value appears in a list

### Level 2: Beginner LeetCode-Style Problems
1. Check if a string is a palindrome
2. Find duplicate values in a list
3. Remove duplicates from a list
4. Count character frequency in a string
5. Find the second largest number in a list

### Level 3: Slightly Stronger Problems
1. Two Sum
2. Valid Anagram
3. First non-repeating character
4. Merge two sorted lists
5. Move all zeros to the end

## Day 1 Optional Practice

### Problem 1
Write a function that takes a string and returns `True` if it is a palindrome, otherwise `False`.

Example:

```python
is_palindrome("madam") -> True
is_palindrome("python") -> False
```
