# Day 1, Exercise 2: First Unique Character

## Today's goal

Use a dictionary to count characters, then use those counts to locate the first character that
appears exactly once.

## Check your current level

Look at this text:

```text
loveleetcode
```

Which character is the first one that appears only once, and what is its index?

Remember that Python indices start at `0`.

## 1. Clarify the contract

The function receives one string and returns:

- the index of its first character that occurs exactly once, or
- `-1` when every character repeats or the string is empty.

Characters are matched exactly:

- `A` and `a` are different characters.
- A space is a character.
- Unicode characters such as `é` are valid.

Examples:

```text
"leetcode"     -> 0
"loveleetcode" -> 2
"aabb"         -> -1
```

## 2. Start with a simple idea

For each character, you could count how many times it appears by scanning the entire string.
When you find a count of one, return that position.

That can scan the same text repeatedly. Its worst-case time cost is O(n²).

## 3. Separate counting from locating

Use two passes:

1. First pass: build a dictionary mapping each character to its total count.
2. Second pass: move through the original string from left to right.
3. Return the first index whose character has a count of `1`.
4. Return `-1` if the second pass finds none.

The dictionary might look like this:

```python
{"l": 1, "e": 3, "t": 1, "c": 1, "o": 1, "d": 1}
```

The original string must be scanned again because dictionary insertion order alone does not
express the requirement as clearly as asking for the first matching index in the input.

## 4. Why two passes are still O(n)

The first pass examines `n` characters and the second pass examines at most `n` characters.

```text
n + n = 2n
```

Big-O ignores constant multipliers, so this is O(n), not O(n²). If there are `k` different
characters, the frequency dictionary uses O(k) extra space.

## Hint ladder

Use only one hint at a time.

### Hint 1

Begin with an empty dictionary named `counts`. For every character, increase its stored count.
The dictionary method `get(character, 0)` can provide zero when the key is new.

### Hint 2

After the counting loop finishes, start a separate loop using `enumerate(text)`.

### Hint 3

Inside the second loop, return the current index when `counts[character] == 1`. Put `return -1`
after the loop.

## Follow-up for after your solution

If characters arrive as a stream and you must report the current first unique character after
every arrival, rescanning everything after each character becomes expensive. You would need both
frequency information and a structure that preserves candidate arrival order.
