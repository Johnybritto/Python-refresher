# Day 2, P06: Detect a Cycle

## Level check

In `A -> B -> C -> B ...`, would following `next` links ever reach `None`?
Answer this before coding.

## One small exercise

Implement `has_cycle(head)` in `detect_cycle.py`.

- Return `True` if following links revisits the same node; otherwise return `False`.
- An empty list has no cycle. A node pointing to itself does have a cycle.
- Equal values in different nodes do not mean there is a cycle.
- Do not change any values or links.
- Assume every link is a `Node` or `None`.

Examples:

```text
1 -> 2 -> 3 -> None       False
A -> B -> C -> B ...      True
7 -> 7 -> None            False (two different nodes)
```

First consider how remembering visited nodes could help. The final target is
O(n) time and O(1) extra space, where n is the number of reachable distinct nodes.

If you need a hint: imagine two references moving through the same list at
different speeds. Compare node identity (`is`), not node values.

Run from the `Apple SRE` folder:

```bash
python3 day02/detect_cycle.py
```

The starter intentionally raises `NotImplementedError`. If your attempt loops
forever, press Ctrl+C and inspect its stopping condition.

After your attempt, explain why it terminates with and without a cycle, and its
time and extra-space complexity. We will discuss returning the cycle's entry
node as a follow-up after review.
