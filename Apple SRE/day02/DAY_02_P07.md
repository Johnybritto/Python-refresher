# Day 2, P07: Valid Parentheses

## Level check

In `([`, which opening bracket must be closed first to keep the nesting valid?

## One small exercise

Implement `is_valid(text)` in `valid_parentheses.py`.

- Input is a string containing only `()[]{}`. Assume valid input characters.
- Return a boolean: every opening bracket must have a matching closing bracket,
  and brackets must close in the correct nesting order.
- The empty string is valid.
- Target O(n) time and O(n) extra space in the worst case.

Examples: `()[]{}` and `([])` are valid; `(]`, `([)]`, and `((` are invalid.

A stack stores items in last-in, first-out order. A Python list supports this
with `append()` to push and `pop()` to remove the most recent item.

First hint if needed: the most recently opened bracket must be closed first.
Try your implementation before asking for further hints.

Run from the `Apple SRE` folder:

```bash
python3 day02/valid_parentheses.py
```

The starter intentionally raises `NotImplementedError` until implemented.
After your attempt, explain why matching counts alone are insufficient and
give the time and extra-space complexity. During review, discuss how you would
handle ordinary text mixed with brackets.
