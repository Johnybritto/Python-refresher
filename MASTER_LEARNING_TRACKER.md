## 7. Important Concepts That Often Get Missed

These are not always “hard,” but they are often skipped or only partly understood.

### Python
- list vs generator
- value vs index
- print vs return
- local vs global scope
- mutable vs immutable intuition
- dictionary key lookup vs list search
- when a generator gets exhausted

### APIs
- request vs response
- GET vs POST
- headers vs payload
- query params vs path params vs body
- status codes
- timeout and retries

### GenAI
- prompt quality affects output quality
- model call should stay in one helper function
- response shape can change
- structured output is different from plain text output
- chat history affects future answers
- retrieval is not the same as generation

### Platform / DevOps
- app layer first, platform layer next
- observability is not just logs
- deployments need rollback thinking
- cost awareness matters in AI systems
- production concerns start after the app works

## 9. Weekly Review Checklist

Once a week, ask:

1. Which topic did I touch but not really understand?
2. Which syntax form did I recognize but could not write?
3. Which concept did a course mention but not explain well?
4. What would likely fail in an interview if asked today?
5. Which gaps should move into the revision guide or syntax tracker?

---

## 10. Short Rule For Outside Courses

Never assume an outside course is complete.

Always check:
- Did it teach the concept?
- Did it show the syntax?
- Did it compare the common variation?
- Did it show a practical example?
- Could I write it myself without looking?

If any answer is “no”, log it here.
