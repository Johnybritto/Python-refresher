# Phase 6: Agents Later

## Goal
Study agents only after the lower-level pieces feel familiar.

## Why This Phase Matters
Agents are often presented as magic, but they are mostly combinations of simpler parts:
- prompting
- tool calling
- memory
- retrieval
- planning
- validation
- retry logic

If those pieces are weak, agent systems become confusing fast.

## Main Topics
- what an agent is
- single-step vs multi-step workflows
- tool selection
- planning
- memory vs retrieval
- agent failure modes
- evaluation of agent behavior

## What You Should Understand By The End
- why an agent is more than a chatbot
- when a workflow does not need an agent
- how tools, planning, and memory fit together
- why agents are harder to test

## Practical Focus
- build one tiny tool-using workflow
- compare fixed workflow vs agent-style workflow
- identify where agent behavior helps and where it adds risk

## Mini Outcomes
By the end of this phase, you should build:
- one tiny tool-using assistant
- one comparison note: workflow vs agent
- one list of agent failure cases you observed

## Suggested Difficulty
Medium to high.

This phase should come later on purpose.
