# Phase 1: GenAI Foundations

## Goal
Understand the core building blocks behind modern LLM systems in a practical way.

## Why This Phase Matters
Before RAG, vector DBs, or agents, you need to understand what the model is doing at a basic level.

If this part is weak, later topics become confusing.

## Main Topics
- tokens
- context window
- prompts
- system instructions
- output variability
- temperature in simple terms
- structured outputs
- parsing and validation
- tool calling basics
- memory vs plain prompt history
- evaluation basics

## What You Should Understand By The End
- why prompts change output quality
- why context size matters
- why models can sound confident and still be wrong
- why structured outputs are useful for code and automation
- why validation is needed even when model output looks good

## Practical Focus
Keep this phase small and hands-on:
- inspect prompt changes
- compare weak vs strong prompts
- ask for JSON output
- validate keys
- observe failure cases

## Mini Outcomes
By the end of this phase, you should build:
- one clean Gemini helper
- one structured output example
- one small validation example
- one short evaluation script

## Why Gemini Is Fine Here
Gemini is just the current provider.

The concepts in this phase apply equally to other model families later.

## Suggested Difficulty
Light to medium.

This phase should feel clear, not overwhelming.
