# Phase 5: Deployment and Platform

## Goal
Learn how to package and deploy a small AI-backed service.

## Why This Phase Matters
This is where your DevOps interest starts connecting strongly with the AI side.

You do not need to become an infra expert immediately.

You need to understand the path from local app to deployed service.

## Main Topics
- Docker basics for AI apps
- environment variables
- dependency management
- service configuration
- logging in deployed environments
- simple deployment flow
- Kubernetes basics later in the phase
- config maps and secrets conceptually
- scaling and resource awareness in simple terms

## What You Should Understand By The End
- how to containerize the app
- how config differs between local and deployed environments
- why secrets handling matters
- what Kubernetes is solving at a high level

## Practical Focus
- containerize a small app
- run it locally in a container
- prepare simple deployment-aware config
- understand what would change for K8s

## Mini Outcomes
By the end of this phase, you should build:
- one Dockerized AI app
- one deployment checklist
- one note on env vars and secrets
- one first-pass K8s understanding summary

## Suggested Difficulty
Medium.

Keep this phase conceptual plus practical, not certification-style.
