# Gemini Free Tier Daily Exercises

Use one main Gemini exercise and one short LeetCode-style basics problem per day.

## Day 1
Gemini task: Use the official Gemini Python SDK to send one short prompt and print only the returned text.
Basics problem: Count how many vowels are in `"hello world"` and print the final count.

## Day 2
Gemini task: Try the same question with two different prompts and note which prompt gives the clearer answer.
Basics problem: Reverse the string `"prompt"` without using slicing and print the reversed string.

## Day 3
Gemini task: Send one prompt, store the prompt and reply in a dictionary, and save that dictionary to a JSON file.
Basics problem: Given `words = ["json", "prompt", "json", "reply"]`, count how many times each word appears.

## Day 4
Gemini task: Ask the model to return JSON with exactly two keys and print the raw returned text.
Basics problem: Given one student dictionary, print `"valid"` only if `name` exists, `age` exists, and `age` is at least `18`.

## Day 5
Gemini task: Wrap one Gemini call in `try` / `except` and print a friendly fallback message if the request fails.
Basics problem: Given `values = ["10", "20", "x", "30"]`, add only the valid integers and print the total.

## Day 6
Gemini task: Build a tiny terminal chatbot that keeps asking for input until the user types `exit`.
Basics problem: Given `messages = ["hi", "hello", "bye"]`, print each message with its position starting from `1`.

## Day 7
Gemini task: Compare one normal response call with one streaming call and write one sentence about the difference.
Basics problem: Given `chunks = ["Py", "thon", " ", "rocks"]`, join them into one string and print it.

## Day 8
Gemini task: Write one small Python function that acts like a tool and describe when a model might want to call it.
Basics problem: Write a function `square_number(n)` that returns the square of `n`, then call it with `5`.

## Day 9
Gemini task: Create one FastAPI `POST` route that accepts a prompt and returns a Gemini reply.
Basics problem: Write a function that takes `name` and `age` and returns `{"name": ..., "age": ...}`.

## Day 10
Gemini task: Move your Gemini call into a helper function and keep your FastAPI route focused on input and output.
Basics problem: Given a list of numbers, write a helper function that returns only the even numbers.

## Day 11
Gemini task: Store three short notes in a list and return the most relevant one for a simple question using keyword matching.
Basics problem: Given `notes = ["python list", "api key", "fastapi route"]` and query `"api"`, print the first matching note.

## Day 12
Gemini task: Send the retrieved note together with the user question and print both the answer and the source note.
Basics problem: Given a list of dictionaries with `question` and `answer`, print the answer for a matching question.

## Day 13
Gemini task: Write three test prompts and record whether each answer was correct, clear, and well formatted.
Basics problem: Write three `assert` tests for a small function like `add_numbers(a, b)`.

## Day 14
Gemini task: Build one small end-to-end Gemini project and write down the one part you most want to improve next.
Basics problem: Given a list of numbers, print the total and the average.
